# 跟读训练台 · Shadowing Lab

面向英语口语自学者的跟读（shadowing）训练台，纯前端实现，数据全部保存在本地浏览器中。

## 功能

- **句子库**：内置示例句库，支持手动添加（句子 / 译文 / 标签 / 难度），按标签、难度筛选与搜索
- **示范播放**：Web Speech API 朗读示范，可选英语语音、0.5×–1.5× 调速
- **录音跟读**：MediaRecorder 录制，实时波形 + 录音时长；麦克风权限被拒绝时给出明确指引
- **对比回放**：先播示范、再播录音，逐句对比
- **练习记录**：每条录音保存时长、时间与 1–5 星自评，逐句查看历史，可回放、改评、删除
- **本地持久化**：句子、记录、音频均存于 IndexedDB，刷新不丢失
- **导入导出**：题库（JSON/TXT）与完整备份（含录音，base64）均可导入导出

## 运行

```bash
npm install
npm run dev      # 开发
npm run build    # 类型检查 + 构建
npm run preview  # 预览构建产物
```

录音功能需要 localhost 或 HTTPS 环境，并授予麦克风权限。

## 导入文件格式

- 完整备份 / 题库：本应用导出的 JSON 文件
- 纯文本：每行一句，`英文 | 中文 | 标签 | 难度`（后三项可省略）
